# v1 readiness

Status checked 2026-10-07. AgentDust 0.3.0 is installable as a limited beta. This page tracks promotion to a scoped stable release. The v1 gate is one controlled end-to-end run on the maintainer's Mac, not a three-Mac, two-week study. Claude Code version claims cover only the lifecycle and attribution behavior represented by fixtures that pass replay. Apply safety is established separately by the apply test suite. Agent Teams remain experimental and outside the v1 support claim.
