# v1 readiness

Status checked 2026-10-07. AgentDust 0.2.0 is installable today. This page tracks promotion to a field validated v1, not whether the tool can be released. A limited beta does not need to wait for a multiweek field study. Do not claim a Claude Code version is supported until its required scenarios pass.

| Criterion | Status | Evidence and remaining work |
| --- | --- | --- |
| 1. Install | Candidate Homebrew acceptance passed; real-account gate open | On 2026-10-07, the [release dry run](https://github.com/hamzahamidi/agentdust/actions/runs/37602662896) installed a generated 0.2.0 candidate formula from M6 source on a clean macOS 15 runner. With temporary `HOME` and Claude config paths, `setup --yes` printed its hook diff before completion, took 0.16 seconds, and passed `setup --check`. This acceptance uses a fake Claude CLI. On this Mac, setup with real Claude Code 2.1.292 wrote to temporary `HOME`, `CLAUDE_CONFIG_DIR` and data directories. It took 1.50 seconds, `setup --check` passed, `claude mcp get agentdust` confirmed the user scoped stdio registration, and `setup --remove --yes` removed it. This did not use a fresh macOS account or run a real Claude session. Repeat install and approved apply with the M6 release on a declared clean account. See [release instructions](../release.md). |
| 2. Hook cost | Repeated replay met pooled target; live workload remains unmeasured | On 2026-10-07, macOS CI [run 37616873637](https://github.com/hamzahamidi/agentdust/actions/runs/37616873637) repeated the three-session replay 20 times. The pooled p50/p95 were 5.55/14.27 ms against the 10/20 ms targets. The median per-replay p95 was 10.17 ms; 18 of 20 replays were under 20 ms, and two measured 21.49 and 45.17 ms. A previous single-run measurement was 25.23 ms in [run 37613966453](https://github.com/hamzahamidi/agentdust/actions/runs/37613966453). The results meet the pooled target but show occasional high tails; the cause is not established. This replay does not measure live Claude Code concurrency. Abrupt exit and Agent Teams remain unrecorded, so the full M6 workload gate remains open. Earlier measurements in [provenance notes](../m2/provenance.md) used a different workload. |

The M6 candidate from [release dry run 37602662896](https://github.com/hamzahamidi/agentdust/actions/runs/37602662896), source commit `d727dda68703df1e9ab632c1ad5b8647bc0d5e08` and SHA-256 `6a84baa674a1ffb342d1baa9f7b87af93da4bdb37b949b5dfebbe8eb742b70f3`, advertised support for protocol `2026-07-28` among five versions through `server/discover` and returned four tools. After `tools/list`, no further requests were sent for 60.0 seconds. In that interval, 42 valid `top` samples displayed 0.0% CPU and 60 `ps` samples measured RSS from 2,416 to 3,152 KiB. Repeat the measurement against the final release artifact if its digest differs. |

## Remaining work

1. Run controlled Homebrew install, session discovery, human-entered approval and one-process signaling on this Mac before a limited beta.
2. Capture abrupt exit and Agent Team scenarios before claiming support for a Claude Code version whose full matrix is not recorded.
3. Measure hook latency for the full captured workload. Repeat interval CPU and resident memory measurements for the release artifact.
4. Collect real use observations after beta. Treat the three-machine, two-week period as evidence for v1 promotion.
5. Reassess suspect false proposals before calling v1 ready.
